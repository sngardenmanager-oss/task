# 설정 탭 구현 문서

## 목적

데이터 내보내기·대량 등록, 사용자와 권한, 가입 승인, 업무 분류, 퇴사 인계와 관리자 전체 수정을 처리한다.

## 관련 코드

- 조합 화면: `SettingsView`
- 기록/엑셀: `DataTransferPanel`
- 관리자 일괄 편집: `AdminMasterEditPanel`
- 사용자·분류·퇴사: `LegacySettingsView`
- 가입 승인 카드: `PendingRegistrationCard`
- 수동 사용자 폼: `MemberForm`
- 가입 API: `/api/auth/registrations`
- Auth 미승인 목록: `listPendingRegistrations`
- 파일 도우미: `downloadBlob`, `csvCell`, `cellText`

## 기간별 CSV 내보내기

기본 기간은 오늘부터 과거 30일이다. 시작일이 종료일보다 늦으면 중단한다.

업무는 지정 기간과 조금이라도 겹치면 포함된다.

```ts
task.date <= to && (task.endDate ?? task.date) >= from
```

특이사항은 발생일이 기간 안에 있으면 포함된다. 분류명·담당자명·상태·우선순위·체크 완료 수를 사람이 읽는 한국어 값으로 변환한다.

CSV 셀의 큰따옴표를 이중화하고 모든 값을 큰따옴표로 감싼다. 파일 앞에 UTF-8 BOM `\uFEFF`를 넣어 Windows Excel에서 한글이 깨지지 않게 한다.

## Excel 대량 등록

관리자만 사용할 수 있다. ExcelJS는 초기 번들에 포함하지 않고 버튼을 누를 때 `import('exceljs')`로 로딩한다.

### 양식 생성

- 시트 `업무업로드`: 업무/루틴 입력 컬럼
- 숨김 시트 `선택목록`: 구분, 우선순위, 상태, 담당자, 분류
- 2~501행: Excel data validation 드롭다운
- 첫 행 고정과 녹색 헤더 스타일
- 참고 링크 형식: `제목|URL|위치;제목|URL|위치`

### 업로드 파싱

1. `업무업로드` 또는 첫 시트를 찾는다.
2. 첫 행의 헤더명→열 번호 Map을 만든다.
3. `구분`, `제목` 필수 컬럼을 검사한다.
4. 셀의 Date, formula result, rich text를 `cellText`로 문자열화한다.
5. `구분=루틴`은 Routine, 나머지는 Task로 변환한다.
6. 없는 분류명은 색상 순환 규칙으로 새 Category를 만든다.
7. 담당자는 이름 또는 이메일로 찾고 없으면 현재 사용자/첫 편집 가능 사용자에게 배정한다.
8. 모든 객체를 한 번의 `updateData`로 추가한다.

## 가입 승인

가입 신청자는 Supabase Auth에는 있지만 `WorkspaceState.members`에는 없는 사용자다. 설정 탭 진입 시에만 목록을 lazy load한다.

관리자는 신청자마다 다음을 정한다.

- 소속 team
- `member` 또는 `commenter` 권한
- 필요하면 Supabase 이메일 인증 강제 완료

승인 API는 Auth 사용자 id를 확인한 뒤 `member-${authUser.id}` id로 멤버를 만들고 workspace 상태를 저장한다.

## 사용자 관리

### 관리자 전체 수정

관리자는 이름, 소속, admin/member/commenter 역할을 수정할 수 있다.

### 수동 사용자 추가

`MemberForm`은 workspace 멤버만 추가한다. Supabase Auth 계정을 생성하지 않으므로 해당 이메일이 로그인하려면 별도의 Auth 가입이 필요하다. 운영에서는 로그인 화면의 가입 신청→승인 흐름을 사용하는 편이 일관적이다.

### 퇴사 처리

관리자 이외 활성 멤버를 비활성화한다.

- 미완료 업무의 assigneeId를 활성 관리자에게 변경
- 담당 루틴도 관리자에게 변경
- 완료된 과거 업무는 원래 담당자를 유지
- 멤버 객체는 삭제하지 않고 `active=false`로 기록 보존

## 분류 관리

- 추가: name, 기본 color, active=true
- 수정: 이름과 6자리 hex color
- 중단/복원: active 토글
- 중단된 분류도 과거 업무에는 남는다.
- 새 업무/루틴 폼에서는 활성 분류만 기본 선택지로 보여준다.

## 권한

- CSV 내보내기는 승인 사용자에게 제공된다.
- Excel 템플릿/업로드, 사용자·권한·분류 변경, 가입 승인과 퇴사 처리는 관리자만 가능하다.
- 서버 `/api/state`는 비관리자가 members/categories를 바꾸면 요청을 거절한다.
- 가입 승인 API도 별도로 admin 여부를 검사한다.

## 재사용 방법

이 설정 화면은 다음 모듈로 나누면 재사용하기 쉽다.

```text
DataExporter<T>
WorkbookTemplateBuilder
WorkbookRowMapper
RegistrationApprovalQueue
MemberLifecycleService
CategoryManager
PermissionMatrix
```

특히 Excel 기능은 화면 코드에서 분리해 column schema 기반으로 만들면 다른 업무 프로그램의 대량 등록에도 그대로 쓸 수 있다.

## 주의할 점

- 대량 업로드는 현재 클라이언트 메모리에서 전체 파일을 파싱한다. 매우 큰 파일은 행 수 제한과 미리보기가 필요하다.
- 수동 사용자 추가와 Supabase Auth 사용자 생성은 원자적으로 연결되지 않는다.
- 마지막 관리자를 일반 역할로 변경하는 것을 막는 별도 검증이 현재 없다. 관리자 0명이 되지 않도록 운영 주의 또는 서버 검증을 추가해야 한다.
- 사용자·분류 수정도 전체 workspace JSONB 자동저장을 유발한다.
