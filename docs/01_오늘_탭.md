# 오늘 탭 구현 문서

## 목적

사용자가 앱을 열자마자 오늘 처리할 업무, 관리자 확인이 필요한 요청, 지연 업무, 7일 이내 마감, 전일 특이사항과 최신 관광뉴스를 한 번에 판단하도록 만든 대시보드다.

## 사용자 화면 구성

1. 상단 지표: 오늘 업무, 완료 요청, 지연 업무, D-day 업무
2. 내 오늘 업무 카드
3. D-day 7일 이내 마감 목록
4. 이번 주 핵심 요약
5. 전일 특이사항
6. 관광뉴스 요약과 전체 보기
7. 현재 작업 트리에서는 오늘 화면 상단에 `전체 새로고침` 버튼을 표시하는 변경이 진행 중이다.

## 관련 코드

- 진입·파생 데이터: `WorkCalendarApp`
- 화면: `TodayView`
- 업무 행: `TaskCard`
- 날짜 계산: `isoDate`, `shiftIsoDate`, `dayDifference`, `dday`
- 상세 열기: `openTask`
- 상태 변경: `setTaskStatus`
- 새 업무: `openCreateTask`, `TaskForm`
- 뉴스 전체 이동: `navigate('news')`, `loadAllNews`

주 소스는 `app/work-calendar-app.tsx`이며 데이터 타입은 `lib/types.ts`의 `Task`, `SpecialNote`, `NewsItem`, `WorkspaceState`다.

## 파생 데이터 계산

부모 컴포넌트는 한 번의 `data.tasks` 순회로 세 목록을 만든다.

```ts
completionRequests: status === 'completion_requested'
overdue: (endDate ?? date) < today && status !== 'completed'
todayTasks: date <= today <= (endDate ?? date) && status !== 'completed'
```

이 계산은 `useMemo`로 감싸 업무 배열 또는 오늘 날짜가 바뀔 때만 다시 수행한다. 기간 업무는 시작일과 종료일 사이의 모든 날에 오늘 업무로 포함된다.

`TodayView` 내부의 D-day 목록은 종료일이 오늘부터 7일 이내인 업무를 선택하고 다음 순서로 정렬한다.

1. 미완료 업무 우선
2. 긴급 → 보통 → 낮음
3. 종료일이 빠른 업무 우선

최근 뉴스는 `collectedAt`이 오늘, 어제, 그제인 항목만 사용한다. 앱 최초 진입에서는 `/api/news?limit=10`만 불러오므로 오늘 화면 때문에 전체 뉴스 payload를 받지 않는다.

## 상호작용과 상태 변화

- 지표 카드를 누르면 캘린더, 전체 업무 또는 알림 화면으로 이동한다.
- 업무 카드를 누르면 `TaskDetail` 모달이 열린다.
- D-day 체크박스는 현재 관리자만 조작할 수 있고 완료/재개 상태로 바뀐다.
- 관광뉴스의 원문 링크는 웹 새 탭 또는 Electron의 기본 브라우저에서 열린다.
- `전체 보기`는 뉴스 화면으로 이동하면서 전체 뉴스 lazy load를 시작한다.

## 권한

- 모든 승인 사용자가 대시보드를 볼 수 있다.
- `commenter`는 업무 추가 버튼과 체크리스트 변경 기능을 사용할 수 없다.
- 최종 완료는 관리자만 가능하다.
- 서버는 `/api/state`의 `validateUpdate`에서 화면 권한을 다시 검증한다.

## 재사용 방법

다른 프로젝트에서 대시보드만 가져가려면 다음 구조로 분리하는 것이 좋다.

```text
useDashboardMetrics(tasks, today)
  ├─ todayTasks
  ├─ overdueTasks
  ├─ completionRequests
  └─ upcomingTasks

DashboardView
  ├─ MetricCards
  ├─ TodayTaskList
  ├─ UpcomingList
  └─ SecondarySummaries
```

반드시 함께 가져갈 요소는 `Task` 상태 모델, 날짜를 `YYYY-MM-DD`로 통일하는 규칙, 기간 포함 조건, 권한별 상태 전환 규칙이다. 관광뉴스와 특이사항은 선택 기능이므로 props로 분리하면 다른 프로그램에서도 쉽게 제거할 수 있다.

## 주의할 점

- `isoDate`는 Asia/Seoul 시간대를 명시한다. 서버 UTC 날짜를 그대로 잘라 쓰면 자정 전후 날짜가 틀어질 수 있다.
- 완료된 업무는 오늘 업무와 지연 업무에서 제외되지만 D-day 화면에는 정렬상 아래쪽에 남을 수 있다.
- 팀원용 D-day 체크 정책을 바꾸려면 화면의 `disabled={!isAdmin}`과 서버 권한 검증을 함께 바꿔야 한다.
- 오늘 화면의 검색창은 업무 검색용이므로 다른 탭에서만 보여주는 현재 UI 변경과 `visibleTasks` 계산은 별개다.
