# 보고서 탭 화면 개선 운영 안내

적용 기준: 2026-10-16. 기획 근거는 `../261016_보고서탭_구조분석_및_화면개선_기획서.html`(상위 폴더)이며, 아래 결정 사항을 반영했습니다.

## 결정 사항과 반영 내용

| 결정 | 반영 |
|---|---|
| 완결 제안 기준: 최종 완료 후 확정본에 보고된 건 | 확정본에 '최종 완료'로 표출된 적이 있는 미완결 행을 **완결 제안**으로 표시합니다. 메인보다 먼저 끝난 하위 일정도 각자 행이라 같은 기준으로 제안됩니다. |
| 완결 제안은 제안 형식 | 자동으로 완결하지 않습니다. **제안 N건 모두 완결** 버튼이나 행별 '완결' 체크로 사람이 확정합니다. 완결 사유가 비어 있으면 "완료 보고됨 (회의일 확정본)"을 채웁니다. 완결한 항목은 다음 회차부터 빠지고 **완결 항목 아카이브**에 남습니다. |
| 프로젝트 기본 3건, 나머지는 펼쳐서 스크롤 | 연결 프로젝트는 주의 순(지연 있음 → D-day 7일 이내 → 승인 대기)으로 3건만 보이고, **나머지 N건 보기**를 누르면 높이가 제한된 상자 안에서 스크롤합니다. 주의 표시가 없으면 최근 등록 순이고, 모두 완료된 프로젝트는 맨 뒤입니다. 하위 일정 목록은 남은 일정만 보이고 완료한 일정은 따로 펼칩니다. |
| 회의 직전 확정본 오류도 제안 형식 | 확정본의 **제출·확정 → 정정 제안**에 누구나(댓글 전용 제외) 고칠 내용을 남깁니다. 관리자가 **대기 제안 반영해 정정본 작성**을 누르면 제안 내용이 정정 사유로 채워진 정정본이 열리고, 반려는 사유가 필요합니다. 확정본 자체는 바뀌지 않습니다. |
| 확정본은 기존처럼 1개월 유지, 작성 기록과 완료 아카이브는 삭제하지 않음 | 월 백업 후 정리 대상은 기존과 같이 **확정한 지 1개월 지난 확정본**뿐입니다(장기 보관함에서 계속 조회). 초안, 보고 추적·완결 아카이브, 정정 제안, 업무·특이사항, 변경 기록(work_records), 장기 보관함(report_archive)은 자동 삭제하지 않습니다. 이 범위를 테스트로 고정했습니다. |

## 화면 변경

- **상단 고정 작업 바**: 스크롤 위치와 관계없이 상태(초안·제출·검토·확정), 저장 안 됨 표시, 내 처리 대기·정정 제안 배지, 진행 단계, 초안 저장·미리보기·제출·확정 이동 버튼과 섹션 바로가기가 보입니다.
- **기간·범위**는 한 줄 요약으로 접혀 있고 '변경'을 누르면 펼쳐집니다.
- **경영 지표**는 탭 위에 한 줄 요약만 두고, 카드·일자별 분포·제주 입도객·구성비는 경영 지표 탭으로 옮겼습니다.
- **보고 행**은 한 줄 요약으로 보이고 '펼치기'를 누른 행만 전체 입력칸이 열립니다. 보기 전환: 보고 대상 / 완결 제안 / 이번 회차 완결.
- **미리보기**는 화면 가운데 창으로 열립니다(Esc 또는 닫기).
- **제출·확정**은 페이지 맨 아래 한 영역에 모았습니다: 보고 제출과 처리 기록 → 보고본 확정·출력 → 정정 제안 → 외부 보관 링크 → 회의 결정과 후속 조치.
- **보고서 보관함** 탭: 최근 확정본, 1개월 지난 확정본(장기 보관함), 완결 항목 아카이브를 한곳에서 봅니다. '보고·업무 기록' 탭은 변경 기록 검색만 남겼습니다.
- 연결 프로젝트의 지연은 캘린더와 같은 규칙(예정 상태만 지연, 진행 중은 기간 초과, 완료 요청은 승인 대기)으로 셉니다. 이미 제출된 보고서의 고정값은 바꾸지 않습니다.
