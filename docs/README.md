# 스누피가든 업무캘린더 기술 문서

이 폴더는 현재 프로그램의 사용자 매뉴얼, 동작 원리, 계정·서비스 연결 구조와 각 화면의 구현 방식을 다른 프로젝트에서도 재사용할 수 있도록 정리한 문서 모음이다.

기준 버전은 2026-09-10의 `main` 브랜치이며, 통합 문서 작성 시점의 배포 커밋은 `f48e62c`이다. 문서 작성 중 별도로 진행 중인 미커밋 UI 변경은 코드의 현재 상태를 기준으로 함께 설명한다.

## 읽는 순서

- 프로그램을 운영하려면 00번 문서의 사용자 매뉴얼과 계정 연결 구조부터 읽는다.
- 특정 화면을 다른 프로그램으로 옮기려면 해당 탭 문서와 10번 공통 기능 문서를 함께 읽는다.
- 실제 코드를 수정할 때는 문서의 함수명으로 `app/work-calendar-app.tsx`를 검색한다. 이 파일이 현재 대부분의 화면 로직을 담고 있다.
- 환경변수 값, Supabase 비밀키, Vercel 토큰은 이 문서에 기록하지 않는다. 변수 이름과 저장 위치만 기록한다.
