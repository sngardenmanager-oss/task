# 보고서 탭

관광뉴스 바로 아래의 **보고서**에서 주간회의 통합 보고서를 작성한다. 모바일에서는 전체 메뉴에서 접근한다.

## 사용 순서

1. 회의일, 기준일, 실적·계획·통계 기간과 내 업무/선택 팀 범위를 설정한다.
2. 최신 업무를 불러오고 보고 문구와 다음 행동을 작성한다. 수동 행, 특이사항, 대표님 안건과 관광뉴스도 선택할 수 있다.
3. 표출 여부와 보고 완결을 각각 선택하고 초안을 저장한다. 원래 업무 상태는 바뀌지 않는다.
4. 경영 지표에서 날짜별 CSV 양식을 내려받아 업로드한다. 신규·변경·동일·오류를 확인한 후 전체 반영한다.
5. 미리보기에서 포함·제외 내용을 확인한 뒤 보고본을 확정한다.
6. 보관함에서 Excel 또는 PDF/인쇄로 재출력한다. 변경은 수정본으로 작성한다. 다음 회차에는 미완결 항목이 다시 기본 포함된다.

## 보존과 권한

- 업무·특이사항 원본과 보고 문구를 분리한다. 삭제되거나 담당자가 바뀐 원본의 추적 항목을 보존한다.
- 완료일이 없는 기존 완료 업무는 날짜를 추정하지 않는다. 관리자가 보고 행에서 확인된 실제 완료일을 입력할 수 있다. 신규 상태 변경은 서버에서 완료 시각과 변경 이력을 기록한다.
- 확정본은 당시 문구, 담당자 이름, 상태, 통계와 서식 버전 1을 저장한다. 서버가 확정본 덮어쓰기·삭제를 거부한다.
- 작성자별 보고 저장 공간을 사용한다. 관리자·일반 업무 작성자는 자신의 보고서를 작성·확정·내보낼 수 있다. 댓글 전용 계정은 보고 API에 접근할 수 없다. 대표님과는 출력물을 공유한다.
- 독립된 weekly_report_state 테이블에 저장하며 버전 비교로 동시 수정 충돌을 거부한다. RLS와 테이블 권한으로 브라우저의 직접 조회를 제한한다.
- 변경 사항은 **초안 저장** 시 서버에 반영된다. 주 메뉴를 바꾸어도 작성 상태는 유지된다. 페이지를 닫을 때 저장하지 않은 변경이 있으면 브라우저가 알린다.

## 통계 기준

- 날짜별 CSV를 지원한다. 아직 제공되지 않은 가로형·기간합계 원본의 자동 변환은 포함하지 않는다.
- 빈칸은 미입력이며 0과 구분한다. 빠진 선택 열은 기존 값을 유지한다. 빈칸 삭제는 별도 선택한다.
- 동일 날짜는 대체하여 재업로드 중복 합산을 방지한다. 업로드 되돌리기는 이후 값과 충돌하지 않을 때만 수행한다.
- 구성비는 기간 인원 합계/기간 전체 합계이다. 전년 같은 날짜로 비교하고 누락 날짜와 전년 0을 표시한다. 윤일의 전년 말일은 2월 28일이며 양쪽 날짜 수를 표시한다.
- 매출·환불·유무료 범위는 원본과 확인하여 비고 및 지표 설명에 남긴다.

## 출력

Excel은 보고요약·이전진행·이후진행·전주후속·경영지표·통계원본 6개 시트로 구성한다. 모든 보고 시트와 PDF에서 표출 제외 행을 제거한다. 고정 머리글, 줄바꿈, 열 너비, 반복 인쇄 머리글, 페이지 번호를 적용한다. PDF는 출력 창에서 PDF로 저장을 선택한다. 보관함 날짜 범위로 여러 Excel을 내려받을 수 있으며 브라우저의 여러 파일 다운로드 허용이 필요할 수 있다. 구글 시트 직접 업로드는 하지 않고 사용자가 다운로드한 Excel을 보관한다.

## 구현 파일 및 검증

- 화면: app/reports-view.tsx
- 이월·통계·추적 로직: lib/reports.ts, lib/report-types.ts
- Excel·인쇄 출력: lib/report-export.ts
- 인증·저장 API: app/api/reports/route.ts
- 테이블: supabase/migrations/0003_weekly_reports.sql
- 검증: node --test tests/reports/reports.test.mjs

새 환경에서는 SQL 마이그레이션을 먼저 적용한다. scripts/migrate-weekly-reports.mjs는 .env.local 연결과 임시 .reports-tools의 pg 및 Supabase CA 인증서를 사용한다. 기존 연결 환경에 테이블을 적용하고 저장·낙관적 잠금·직접 접근 제한을 트랜잭션 롤백 방식으로 검증했다.

정적 검사, 프로덕션 빌드, 19개 회귀 검증과 Excel 생성 후 재읽기를 수행했다. 실제 브라우저 조작, 구글 시트 업로드와 인쇄물 시각 검증은 수행하지 않았다.
