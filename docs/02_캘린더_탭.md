# 캘린더 탭 구현 문서

## 목적

팀 업무와 반복 루틴을 월간 달력에서 확인한다. 여러 날 이어지는 업무는 각 날짜 셀의 높이를 늘리는 방식이 아니라 주 단위 가로 막대로 겹쳐 표시한다.

## 관련 코드

- 월간 화면: `CalendarView`
- 날짜별 전체 목록: `DayItemsModal`
- 반복 판정: `routineOccursOnDate`
- 날짜 도우미: `isoDate`, `formatDate`, `dayDifference`
- 업무 생성/상세: `openCreateTask`, `openTask`
- 루틴 상세: `openRoutine`, `InteractiveRoutineDetail`
- iCalendar 내보내기: `exportCalendarIcal`, `icalDate`, `icalEscape`, `downloadBlob`
- 동기화: `refreshWorkspace`

## 42칸 월간 그리드

현재 월의 첫 요일 `offset`과 말일 `days`를 계산해 항상 6주 × 7일, 총 42칸을 만든다. 빈 칸은 `null`, 실제 날짜는 `dateKey(day)`로 `YYYY-MM-DD` 문자열이 된다.

문자열 날짜 형식이 고정되어 있으므로 다음과 같은 사전식 비교가 시간 계산 없이 가능하다.

```ts
task.date <= currentDate && (task.endDate ?? task.date) >= currentDate
```

## 다일 업무 막대 알고리즘

각 주마다 다음 과정을 수행한다.

1. 모든 업무 중 그 주와 겹치는 날짜 열 번호를 찾는다.
2. 첫 열을 `start`, 마지막 열을 `end`로 하는 segment를 만든다.
3. 시작 열 오름차순, 길이가 긴 일정 우선으로 정렬한다.
4. `laneEnds` 배열을 사용해 기존 막대와 겹치지 않는 첫 lane을 배정한다.
5. CSS Grid의 `gridColumn: start + 1 / end + 2`로 막대를 여러 날짜 위에 걸친다.
6. 일정이 주를 넘어가면 다음 주에서 새 segment가 생성되어 자연스럽게 이어진다.

```text
월  화  수  목  금  토  일
        [행사 A ─────────]
[행사 A ───]
```

한 주에서 업무 막대는 최대 3 lane까지만 표시한다. 그 이상과 루틴 2개 초과분은 날짜 셀의 `+N개 더보기`로 합산한다. 더보기를 누르면 `DayItemsModal`이 해당 날짜와 겹치는 모든 업무·루틴을 보여준다.

## 루틴 표시

`routineOccursOnDate`는 루틴이 활성 상태이고 대상 날짜가 `nextDate` 이후인지 먼저 확인한다.

| cadence 문자열 | 판정 |
|---|---|
| `매일` 포함 | 모든 날짜 |
| `격주`, `2주` 포함 | nextDate부터 14일 배수 |
| `매주`, `주간`, `주 1회` 포함 | nextDate부터 7일 배수 |
| `매월`, `월간`, `월 1회` 포함 | nextDate와 일(day)이 같은 날짜 |
| 그 외 | nextDate 당일만 |

즉 `매주 월요일`의 요일 문장을 직접 해석하는 것이 아니라, 사용자가 월요일인 `nextDate`를 지정하면 이후 7일 간격으로 표시하는 구조다.

## 날짜 셀 상호작용

- 빈 영역 클릭: 해당 날짜가 기본값인 `TaskForm`을 연다.
- 업무 막대 클릭: `TaskDetail`을 연다.
- 루틴 버튼 클릭: `InteractiveRoutineDetail`을 연다.
- 오늘 버튼: 현재 서울 날짜가 속한 월로 이동한다.
- 이전/다음 화살표: `monthCursor`를 한 달 이동한다.
- 새로고침: 현재 로컬 상태를 `PUT /api/state`로 병합·저장하고 서버 결과를 다시 적용한다.

## iCal 내보내기

`exportCalendarIcal`은 모든 업무를 RFC 5545 형태의 `VEVENT`로 만든다.

- 종일 일정은 `VALUE=DATE`를 사용한다.
- 종료일은 iCalendar 규칙상 exclusive이므로 실제 종료일 다음 날을 `DTEND`로 쓴다.
- 제목, 설명, 분류, 담당자 문자열의 역슬래시·세미콜론·쉼표·줄바꿈을 escape한다.
- 완성된 문자열을 Blob으로 만들어 `.ics` 파일로 다운로드한다.

## 성능 기술

- 일정 막대는 날짜 셀 내부에 복제하지 않고 주 위의 absolute overlay에서 한 번만 렌더링한다.
- 화면 높이는 일정 개수와 무관하게 유지된다.
- 표시 제한을 넘긴 항목은 더보기 모달에서만 렌더링한다.
- 검색·상태·담당자 필터를 통과한 `visibleTasks`만 캘린더에 전달된다.

## 재사용 방법

다른 프로젝트에서는 다음 네 부분을 독립 모듈로 추출한다.

1. `buildMonthCells(year, month): (number | null)[]`
2. `splitTasksIntoWeeklySegments(tasks, weekDates)`
3. `assignLanes(segments, maxLanes)`
4. `CalendarGrid`, `AllDayEventLayer`, `DayOverflowDialog`

데이터는 최소한 `{id, title, startDate, endDate, color}`만 있으면 된다. 현재 `Task` 전체를 넘기지 않도록 adapter를 두면 영업 일정, 예약, 프로젝트 마일스톤에도 그대로 재사용할 수 있다.

## 주의할 점

- 종료일 비교는 양 끝 포함(inclusive)이다.
- 같은 주에 4개 이상 겹치면 일부 막대가 숨겨지고 더보기 숫자로 이동한다.
- 월간 루틴에서 29~31일은 해당 날짜가 없는 달에 표시되지 않는다.
- 복잡한 반복 규칙이 필요하면 문자열 정규식 대신 RRULE 또는 구조화된 recurrence 타입으로 교체해야 한다.
