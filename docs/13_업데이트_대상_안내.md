# 업데이트 대상 안내

2026-09-20 사용자 요청 기준.

## 이번 업데이트 대상

현재 `스누피가든_조직_업무프로그램빌드/snoopy-work-calendar`의 **스누피가든 업무캘린더**만 업데이트한다.

- 웹: https://snoopy-work-calendar-pig15.vercel.app
- Windows: `desktop-dist/스누피가든-업무캘린더-0.1.0.exe`
- Windows 앱은 위 웹 서비스에 연결하므로 웹 배포 완료 후 새로고침하거나 다시 실행하면 새 기능을 사용한다.
- 주간회의 보고서, 초안·확정본 보관, 후속 확인, 경영 지표, Excel 및 PDF/인쇄가 대상이다.

## 별도 앱: 스누피가든 업무

설치형 **스누피가든 업무**(`team-calendar-desktop`, `teamflow-calendar.vercel.app`)는 별도 데이터·로그인을 사용하는 다른 앱이다.

사용자 요청에 따라 이번에는 해당 앱에 보고서를 추가하거나 배포하지 않는다. 준비했던 검토용 코드는 현재 프로젝트의 `outputs/teamflow-report-patch/`에만 남아 있으며, 실행·배포 대상이 아니다. 별도 앱의 실제 소스에는 보고서 변경이 적용되지 않았음을 확인했다.

향후 별도로 추진한다면 해당 앱의 일정과 일자별 특이사항으로 독립 보고서를 만들고, 독립 저장소와 권한 검증을 준비해야 한다. 이는 설명용 메모이며 이번 업데이트에 포함하지 않는다.
